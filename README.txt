# واقعیت جهان
نسخه اولیه وب‌سایت فارسی، راست‌چین و واکنش‌گرا.

## انتشار با GitHub Pages
1. فایل `index.html` را در ریشه مخزن GitHub بارگذاری کن.
2. وارد Settings مخزن شو.
3. در بخش Pages، گزینه انتشار از شاخه `main` و پوشه `/ (root)` را انتخاب و Save کن.
4. پس از آماده‌شدن، آدرس سایت در همان بخش نمایش داده می‌شود.

توجه: فرم عضویت نمایشی است و هنوز به سرویس ایمیل یا پایگاه داده وصل نیست. متن‌های مقاله هم نمونه‌اند و بهتر است با مطالب بررسی‌شده و اختصاصی جایگزین شوند.
